# STM32 Smart Plant Care System (Rust)

基于 Rust 嵌入式生态（RTIC）构建的智能盆栽护理系统固件，运行于 STM32F103 微控制器。

## 功能模块

本系统采用模块化设计，主要包含以下组件：

### 核心控制 (App)
- 基于 **RTIC (Real-Time Interrupt-driven Concurrency)** 框架。
- 负责系统初始化、任务调度、资源管理及中断处理。
- `TIM2` 定时器用于周期性遥测（Telemetry）及执行器脉冲计时。

### 传感器模块 (Sensors)
负责采集环境数据：
- **温湿度**: DHT11 传感器。
- **光照强度**: BH1750 传感器 (I2C 接口)。
- **土壤湿度**: 电容/电阻式传感器 (ADC 模拟量采集)。

### 执行器模块 (Actuators)
控制外部设备，支持开关及定时脉冲（自动关闭）模式：
- **水泵 (Water Pump)**: 用于自动浇水。
- **补光灯 (Grow Light)**: 用于植物补光。
- **风扇 (Fan)**: 用于通风散热。
- **蜂鸣器 (Buzzer)**: 用于状态提示或报警。

### 显示模块 (Display)
- **ST7735 TFT 屏幕**: 通过 SPI 接口驱动。
- 实时显示当前温湿度、光照及土壤湿度数据。

### 通信模块 (Protocol)
- **USART1**: 与上位机（如 ESP32/ESP8266）通信。
- **NDJSON 协议**: 使用行分隔的 JSON 格式交互命令与数据。

| 类型 | 功能 | 引脚 | 模式/说明 |
| :--- | :--- | :--- | :--- |
| **传感器** | 土壤湿度 | `PA0` | ADC 模拟输入 |
| | DHT11 数据 | `PB5` | 浮空输入 / 开漏输出 |
| | BH1750 SCL | `PB6` | I2C1 时钟 |
| | BH1750 SDA | `PB7` | I2C1 数据 |
| **执行器** | 蜂鸣器 | `PA1` | 推挽输出 (低电平触发) |
| | 水泵 | `PB0` | 推挽输出 (高电平触发) |
| | 补光灯 | `PB1` | 推挽输出 (高电平触发) |
| | 风扇 | `PB10` | 推挽输出 (高电平触发) |
| **显示屏** | RST (复位) | `PA2` | 推挽输出 |
| (ST7735) | CS (片选) | `PA3` | 推挽输出 |
| | DC (数据/命令) | `PA4` | 推挽输出 |
| | SCK (时钟) | `PA5` | SPI1 复用推挽 |
| | MISO | `PA6` | SPI1 浮空输入 (未使用) |
| | MOSI (数据) | `PA7` | SPI1 复用推挽 |
| **通信** | USART1 TX | `PA9` | 复用推挽 (115200bps) |
| | USART1 RX | `PA10` | 浮空输入 |
